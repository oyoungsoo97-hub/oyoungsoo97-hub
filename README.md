### How I work

Define the problem → explore the interaction → build a prototype → check its behavior → document the decision.

I use Figma and Adobe XD for interface work, with a broader practice in brand, editorial, motion and 3D. My recent web prototypes use AI-assisted implementation and automated checks; the case studies distinguish design intent, observed behavior and questions still awaiting user research.
